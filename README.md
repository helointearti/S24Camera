# S24 Caméra — appli photo pour Galaxy S24 Ultra

## Installer
1. Ouvrir ce dossier dans **Android Studio** (Ladybug ou plus récent) → laisser la synchro Gradle se faire.
2. Sur le S24 Ultra : Paramètres → À propos du téléphone → Informations sur le logiciel → taper 7 fois sur « Numéro de version » → activer **Débogage USB** dans Options de développement.
3. Brancher le téléphone, cliquer sur ▶ Run.
   (Ou : Build → Build APK(s), puis copier `app/build/outputs/apk/debug/app-debug.apk` sur le téléphone.)

## Fonctions
- Modes **PHOTO / VIDÉO** (toucher le nom, ou glisser gauche/droite sur l'aperçu)
- Arrière : raccourcis zoom **0.6x · 1x · 2x · 3x · 5x · 10x** + pincer pour zoomer (jusqu'à 100x)
- Avant : **selfie grand angle** par défaut (tout le capteur), bouton pour passer en cadrage serré
- **Photo pendant la vidéo** : bouton appareil photo à gauche du déclencheur pendant l'enregistrement
- Pause / reprise de la vidéo, chrono d'enregistrement, vidéo 4K (repli en Full HD)
- Flash (off / auto / on), flash d'écran pour les selfies
- Retardateur 2 / 5 / 10 s, grille, format 3:4 ou 9:16
- Toucher pour la mise au point, touches volume = déclencheur
- Glisser haut/bas = changer de caméra
- Fichiers enregistrés dans **DCIM/S24Camera** (visibles dans la Galerie Samsung)
